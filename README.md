# PlantCare-AI

**AI-Based Plant Care Advisor Chatbot**

PlantCare AI is an AI-powered chatbot that helps users understand plant care and maintenance.

## Features
- AI-based plant care assistance
- Plant information and guidance
- Watering and sunlight recommendations
- Plant database using MySQL
- Chatbot powered by Ollama

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- AI Model: Ollama (Llama 3.2)
- Database: MySQL

## Project Purpose
To provide simple and useful information to users about plant care through an AI-powered chatbot.
